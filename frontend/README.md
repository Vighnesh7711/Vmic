# 🎙️ VMIC Frontend (Next.js + Web Audio Engine)

This is the Next.js 16 (React 19) frontend application for the **VMIC Classroom Wireless Audio Platform**.

---

## ⚡ Quick Start (Frontend)

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Generate Development SSL Certificates**:
   ```bash
   node scripts/generate-cert.js
   ```

3. **Start HTTPS Dev Server**:
   ```bash
   npm run dev
   ```

4. **Open Host Console**:
   👉 `https://localhost:3000/host/create`
